# Nova - Glossaire Technique et Métier

## A
*   **ACID** : Ensemble de propriétés (Atomicité, Cohérence, Isolation, Durabilité) garantissant qu'une transaction de base de données est traitée de façon fiable.
*   **API (Application Programming Interface)** : Interface permettant à l'UI et au Worker de communiquer avec le serveur.
*   **Asynchrone (async/await)** : Mode d'exécution permettant de ne pas bloquer le programme pendant une opération longue (ex: attente d'une réponse réseau).

## C
*   **CRUD** : Acronyme pour Create, Read, Update, Delete. Désigne les quatre opérations de base pour la gestion des données.
*   **CSS Selector** : Motif utilisé pour cibler des éléments HTML spécifiques dans une page (utilisé pour la détection de stock).

## D
*   **DOM (Document Object Model)** : Structure hiérarchique d'une page HTML.

## H
*   **Headless Browser** : Navigateur web sans interface graphique (ex: Playwright), utilisé pour scraper des sites complexes.
*   **HTTPX** : Bibliothèque Python rapide et asynchrone pour effectuer des requêtes HTTP.

## I
*   **I/O Bound** : Se dit d'un programme dont la vitesse est limitée par les entrées/sorties (réseau, disque) plutôt que par la puissance du processeur.

## J
*   **JSONB** : Format de stockage de données JSON binaire dans PostgreSQL, permettant des recherches rapides et l'indexation.
*   **JWT (JSON Web Token)** : Jeton sécurisé utilisé pour l'authentification des utilisateurs.

## O
*   **ORM (Object-Relational Mapping)** : Technique permettant d'interagir avec une base de données en utilisant des objets plutôt que du SQL brut (ex: SQLAlchemy).

## R
*   **RBAC (Role-Based Access Control)** : Gestion des accès basée sur les rôles (ex: USER vs ADMIN).
*   **RGPD** : Règlement Général sur la Protection des Données.
*   **Responsive Design** : Capacité d'une interface à s'adapter à la taille de l'écran (mobile, tablette, bureau).

## S
*   **Scraping** : Technique d'extraction automatique de données depuis des sites web.
*   **SSRF (Server-Side Request Forgery)** : Type de faille de sécurité où un attaquant force le serveur à effectuer des requêtes vers des destinations non autorisées.
*   **Suivi (ou Watch)** : Terme métier désignant la surveillance d'un produit spécifique par un utilisateur pour détecter son retour en stock.

## T
*   **Throttling** : Limitation volontaire du débit de requêtes pour éviter de surcharger un serveur distant.

## W
*   **Worker** : Processus d'arrière-plan chargé d'exécuter les tâches répétitives (vérification des stocks).
